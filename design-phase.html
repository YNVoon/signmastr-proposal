Full Design Phase

Detailed design creation that occurs AFTER payment is received - the production-ready design for manufacturing.

Important Distinction

Basic Draft (Pre-Payment): Preliminary layout created for quotation purposes

Full Design (Post-Payment): Detailed production-ready design covered on this page

Full Design Assignment

1. Payment Triggers Full Design

Upon payment confirmation, project moves to "Full Design Queue"

2. Automatic Designer Assignment

Important: Project is automatically assigned to the designer who created the basic draft. This ensures continuity and rewards complete project ownership.

3. Designer Notification

Designer receives notification that their project is ready for full design

4. Designer Access

Designer can view:

  • Their own previously created basic draft
  • All project details and customer requirements
  • Site photos and measurements
  • Customer feedback/comments from quotation stage
  • Approved quotation details

5. Administrator Oversight

Administrator can view assignment but designer is already pre-assigned from basic draft phase

Design Upload & Approval Process

1. Designer Uploads Design

Designer uploads design files to project portal

2. System Notifications

System notifies:

  • Salesperson (required)
  • Customer (optional)
  • Administrator (for tracking)

3. Salesperson Review

Salesperson reviews design and can:

  • Share with customer for approval
  • Request amendments with specific notes
  • Approve design if customer delegates authority

4. Amendment Process (if needed)

If amendments requested:

  • Designer receives amendment notes
  • Designer updates design
  • Designer uploads revised version
  • Process repeats until approval

5. Design Approval Options

Design can be approved by:

  • Customer approval (preferred method)
  • Salesperson approval (if customer delegates)

6. Trigger Manufacturing

Approved design automatically triggers manufacturing phase
