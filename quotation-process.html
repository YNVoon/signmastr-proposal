Quotation Process

From site visit to quotation approval and payment collection - the complete workflow for converting interested leads into paying customers.

Process Overview

1. Site Visit & Information Gathering

Salesperson collects all necessary information from customer site

2. Basic Draft Creation

Designer creates basic layout for quotation purposes (not detailed design)

3. Quotation Creation

Salesperson prepares quotation based on basic draft

4. Quotation Approval

Administrator reviews and approves quotation

5. Customer Review

Approved quotation sent to customer for decision

6. Payment Collection

50% upfront payment collected to proceed to full design

Site Visit & Information Gathering

Workflow

Schedule Site Visit

Salesperson schedules site visit with interested customer

Conduct Site Visit

Salesperson visits site and collects required information:

  • Site photos (multiple angles, lighting conditions, mounting locations)
  • Measurements (dimensions, clearances, mounting points)
  • Customer logo and branding materials
  • Specific requirements and preferences
  • Installation location details
  • Power supply availability (for LED signage)
  • Local regulations or restrictions

Upload Materials

Salesperson uploads all collected materials to the system

Status Update

Project status automatically updates to "Site Visit Completed"

Site Visit Quality Checklist

Complete Documentation

All required fields filled and site visit marked complete

High-Quality Photos

Minimum 5 photos uploaded from multiple angles

Accurate Measurements

Precise measurements for design specifications

Branding Materials

Logo and branding files collected and uploaded

Basic Draft for Quotation

Important Distinction: The basic draft is a preliminary layout created for quotation purposes only. This is NOT the detailed full design that will be used for manufacturing. The full design phase occurs AFTER payment is received.

Workflow

1. Automatic Queue Assignment

After site visit completion, project automatically moves to "Awaiting Basic Draft" and appears in the designer queue (visible to all designers)

2. Designer Selection

Designer selects job from queue and reviews:

  • Site photos
  • Measurements
  • Customer requirements
  • Branding materials

3. Designer Assignment Lock

Critical: Once a designer accepts the basic draft job, they are automatically assigned to the full design phase for this project. This ensures continuity and quality.

4. Create Basic Layout

Designer creates basic layout draft (not detailed design)

Designer can communicate with salesperson for clarifications within the system

5. Upload Basic Draft

Designer uploads basic draft to project

6. Salesperson Review

Salesperson reviews basic draft and either approves or requests revisions

7. Status Update

Once approved by salesperson, project status updates to "Basic Draft Completed"

8. Designer Remains Assigned

Designer remains assigned to this project for the full design phase (after payment)

Designer Performance: Designers are evaluated on turnaround time, first-time approval rates, and quality of handoffs. See the Performance Scoring page for complete details.

Quotation Creation

Workflow

1. Create Quotation

Salesperson creates quotation based on basic draft, including:

  • Customer details
  • Project specifications (based on basic draft)
  • Itemized pricing
  • 50% upfront payment requirement
  • Terms and conditions
  • Basic draft preview (optional)

2. Generate Document

System generates quotation document via Autocount API

3. Submit for Approval

Quotation automatically submitted for administrator approval

Quotation Contents

Customer Information

  • Company name
  • Contact person
  • Address
  • Contact details

Project Details

  • Signboard type
  • Dimensions
  • Materials
  • LED/lighting specifications

Pricing

  • Itemized costs
  • Subtotal
  • Tax (if applicable)
  • Total amount

Payment Terms

  • 50% upfront requirement
  • 50% upon completion
  • Payment methods
  • Validity period

Quotation Approval

Workflow

1. Notification

Administrator receives notification of pending quotation

2. Review

Administrator reviews quotation details, pricing, and terms

3. Decision

Administrator can:

  • Approve quotation - Ready to send to customer
  • Reject with comments - Return to salesperson for revision
  • Request modifications - Specify required changes

4. Send to Customer

Upon approval, quotation sent to customer via email/WhatsApp

Quotation Status Tracking

Approved Admin Approved
Sent to Customer Awaiting Customer
Accepted by Customer Customer Approved
Rejected by Customer Declined

Payment Collection

Requirements

50% Upfront Payment

Required before proceeding to full design phase

Trigger: Payment confirmation automatically moves project to "Full Design Queue"

Payment Recording

  • Payment amount
  • Payment date
  • Payment method
  • Receipt/reference number

Linked Records

  • Linked to customer account
  • Linked to project
  • Linked to quotation
  • Visible to all relevant team members

Status Visibility

  • Payment pending
  • Payment confirmed
  • Amount received
  • Outstanding balance

What Happens Next?

Payment Confirmed

50% upfront payment recorded in system

Project Status Updated

Status automatically changes to "Full Design Queue"

Designer Notification

The designer who created the basic draft receives notification that their project is ready for full design

Full Design Phase Begins

Designer starts creating the detailed design for manufacturing
