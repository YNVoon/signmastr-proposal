User Roles

The Signmastr Business Management System supports six distinct user roles, each with specific responsibilities and access levels.

Role Definitions

Role Responsibilities
Administrator System oversight, quotation approval, installer assignment, overall management
Salesperson Lead handling, customer communication, quotation preparation, design coordination
Designer Design creation, file uploads, design amendments
Manufacturer Production planning, manufacturing execution, material management
Installer Installation execution, site documentation, customer sign-off
Customer View project status, approve designs, make payments

Detailed Role Descriptions

👨‍💼 Administrator

Primary Functions:

  • System configuration and user management
  • Review and approve all quotations before sending to customers
  • Assign installers to completed manufacturing jobs
  • Monitor system-wide performance metrics
  • Assign project complexity levels (Simple, Medium, High)
  • Handle performance scoring disputes and corrections
  • Review and distribute customer feedback
  • Manage quarterly bonus calculations

Dashboard Access:

  • Total active projects by stage
  • Pending quotation approvals
  • Projects awaiting payment
  • Design queue length
  • Manufacturing queue length
  • Installations scheduled vs completed
  • Outstanding invoices
  • Revenue summary

💼 Salesperson

Primary Functions:

  • Receive and respond to new leads from WhatsApp and website
  • Communicate with potential customers
  • Schedule and conduct site visits
  • Collect site photos, measurements, and branding materials
  • Upload site visit documentation
  • Review and approve basic drafts from designers
  • Create quotations based on basic drafts
  • Submit quotations for administrator approval
  • Send approved quotations to customers
  • Collect 50% upfront payment
  • Share full designs with customers for approval

Dashboard Access:

  • Active leads and projects
  • Leads requiring follow-up
  • Quotations pending customer response
  • Projects in design phase
  • Upcoming installations
  • Personal sales performance metrics
  • Team performance comparison

Performance Tracking:

  • Number of leads assigned
  • Response time to new leads
  • Conversion rate (leads to quotations)
  • Quotation acceptance rate
  • Total sales value
  • Average deal size

🎨 Designer

Primary Functions:

  • View available basic draft jobs in queue
  • Select and accept basic draft jobs
  • Create basic layout drafts for quotations
  • Communicate with salespeople for clarifications
  • Upload basic drafts for salesperson review
  • Automatic assignment to full design for projects where they created the basic draft
  • Create detailed full designs after payment received
  • Upload design files with version control
  • Make design amendments based on feedback
  • Provide manufacturing specifications

Dashboard Access:

  • Available basic draft jobs (can select from queue)
  • My active basic drafts in progress
  • My projects awaiting payment (basic draft completed)
  • My full design projects ready to start (payment received)
  • My active full design projects
  • Full designs pending approval
  • Designs requiring amendments
  • Completion metrics (basic drafts vs. full designs)
Important: The designer who creates the basic draft is automatically assigned to complete the full design for that project, ensuring continuity and quality.

🏭 Manufacturer

Primary Functions:

  • View manufacturing job queue
  • Accept and start manufacturing jobs
  • Review design specifications and materials needed
  • Check material inventory and requisition if needed
  • Execute production work
  • Upload photo documentation during production
  • Complete safety checklists
  • Submit jobs for quality check
  • Mark completed jobs as "Ready for Installation"
  • Report design issues early in the process
  • Provide material feedback for future improvements

Dashboard Access:

  • Jobs in manufacturing queue
  • Jobs in progress
  • Completed jobs awaiting installation
  • Material stock levels
  • Production capacity overview

🔧 Installer

Primary Functions:

  • View assigned installation jobs via mobile app
  • Access customer location and contact information
  • View design specifications and installation requirements
  • Navigate to installation site
  • Perform site check-in with location and "before" photo
  • Complete installation work
  • Report any issues during installation
  • Perform site check-out with "after" photo
  • Collect customer digital signature on delivery order
  • Upload signed delivery order to system
  • Rate handoff quality from manufacturing

Mobile App Features:

  • Job list and schedule
  • GPS navigation to site
  • Photo capture and upload
  • Digital signature collection
  • Issue reporting
  • Work history

👤 Customer

Primary Functions:

  • View real-time project status
  • See design previews and files
  • Approve or request amendments to designs
  • View quotations and invoices
  • Track payment status
  • Access project history and documents
  • Provide feedback and ratings
Note: Customer portal is marked as optional future enhancement in the implementation roadmap.

Role Interactions

Typical Project Flow Across Roles

Lead Capture → Salesperson

System automatically assigns new leads to salespeople based on WhatsApp number or round-robin distribution

Salesperson → Designer (Basic Draft)

After site visit, salesperson uploads materials. Designer selects job from queue and creates basic draft

Designer → Salesperson

Basic draft submitted for salesperson review and approval

Salesperson → Administrator

Quotation created and submitted for administrator approval

Administrator → Customer

Approved quotation sent to customer

Payment → Designer (Full Design)

50% payment triggers full design phase. Same designer automatically assigned

Designer → Manufacturing

Approved full design sent to manufacturing queue with specifications

Manufacturing → Installer

Completed product ready for installation. Administrator assigns installer

Installer → Customer

Installation completed with customer sign-off

Administrator → Customer

Final invoice sent for remaining 50% payment
