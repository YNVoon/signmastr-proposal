Installation & Delivery

Complete installation workflow from scheduling to customer sign-off using the dedicated installer mobile app.

Installation Scheduling

1. Manufacturing Completion Notification

When manufacturing marks job as complete, administrator receives notification

2. Administrator Review

Administrator views:

  • Completed jobs pending installation
  • Installer availability and schedule
  • Customer location and requirements
  • Project complexity and timeline

3. Installer Assignment

Administrator assigns installer to project based on availability and location

4. Delivery Order Generation

System generates delivery order via Autocount API

5. Installer Notification

Installer receives notification with complete job details via mobile app

Installer Mobile App

Dedicated Mobile Application: Installers use a specialized mobile app for all installation activities, from job viewing to customer sign-off.

Delivery Order Management

Delivery Order Features

📄 Document Generation

Delivery order generated from Autocount API

  • Project details
  • Items delivered/installed
  • Customer information
  • Terms of service

✍️ Digital Signature

Customer signature captured digitally on mobile device

  • Touchscreen signature
  • Date and time stamped
  • GPS location recorded
  • Legally binding

📥 PDF Generation

System generates PDF of signed delivery order

  • Includes all details
  • Contains customer signature
  • Timestamped and verified
  • Automatically stored

💾 Automatic Storage

Signed delivery order stored in project records

  • Linked to project
  • Accessible by all team members
  • Archived for future reference
  • Audit trail maintained
