Project Closure & Invoicing

Final invoicing, payment collection, and project archival - completing the project lifecycle.

Project Completion Triggers

✅ Installer Completion

Installer marks installation as complete via mobile app

📄 Signed Delivery Order

Signed delivery order uploaded to system

👨‍💼 Administrator Confirmation

Administrator reviews and confirms completion

📊 Status Update

System updates project status to "Installation Complete"

Project Completion Workflow

1. Automatic Status Update

System automatically updates project status to "Installation Complete"

2. Notifications Sent

Notification sent to:

  • Administrator (for review and invoice generation)
  • Salesperson (for customer follow-up)
  • Accounting team (for payment tracking)

3. Final Invoice Ready

System ready to generate final invoice for remaining payment

Final Invoice Generation

1. Administrator Review

Administrator reviews project completion:

  • Signed delivery order verified
  • Installation photos reviewed
  • Customer signature confirmed
  • No pending issues or complaints

2. System Calculates Remaining Payment

System automatically calculates remaining 50% payment:

  • Original quotation total
  • Less: 50% deposit already paid
  • Plus: Any additional charges or modifications
  • Equals: Final balance due

3. Generate Final Invoice

System generates final invoice via Autocount API

4. Invoice Contents

Final invoice includes:

  • Previous payment (50% deposit) - marked as paid
  • Remaining balance (50%)
  • Any additional charges (if applicable)
  • Payment terms and due date
  • Payment methods accepted

5. Invoice Sent to Customer

Invoice sent via email and/or WhatsApp

Customer Rating Collection

Automated Customer Feedback: After installation completion, system sends automated customer rating request for quality assurance and team performance tracking.

Rating Collection Process

1. Automatic Rating Request

System sends automated rating request via SMS, email, or WhatsApp

2. Customer Submits Rating

Customer submits 1-5 star rating through simple digital form

3. Optional Text Feedback

Customer can provide additional comments or feedback

4. Team Identification

System identifies all team members who worked on the project

5. Points Distribution

System automatically awards customer impact points to all team members

Team Performance Recognition

Performance Measurement: All team members who contributed to a project are evaluated based on customer ratings, project completion timelines, and overall quality. For complete scoring details including customer impact points, project success bonuses, and recognition criteria, see the Performance Scoring page.
